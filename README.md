# AI-Native Blog

**Agent-Native knowledge on AI agent engineering.** Humans read the pages; agents discover and call the same content via `/api/discover.json`, MCP tools, and an installable Skill.

🔗 **https://chengguruchun.github.io**

Agent 工程 · 复杂系统 · 多元思考。记录思考、验证观点、持续进化 —— 不只是博客，而是面向 Agent 的个人知识基础设施。

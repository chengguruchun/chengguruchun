## 代表项目

### [AI Knowledge Lab](https://chengguruchun.github.io)

面向 Agent 的个人知识基础设施实验：探索如何把静态文章组织成可发现、可检索、可调用、可追溯的知识系统。

- **Agent 接入：** 通过 Skill、Discovery API、JSON Catalog 与 Markdown 内容提供统一发现入口。
- **知识治理：** 使用元数据、Git 版本历史和知识状态索引管理内容。
- **工程验证：** 将内容索引一致性、页面元数据和发布检查纳入自动化工作流。
- **架构取舍：** 采用 GitHub Pages 与静态文件优先的方案，控制基础设施复杂度，同时保持内容可追溯。

> 这是持续演进中的个人工程项目；具体能力以仓库实现和验证结果为准。

### 技术研究与架构实践

- **Agent Runtime / Harness：** 任务循环、工具执行、状态管理、Checkpoint、错误恢复与结果验证。
- **模型接入与 Gateway：** 多供应商协议适配、流式响应、路由、用量计量与插件化扩展。
- **IoT / Device Agent：** 设备能力抽象、工具接口、权限边界与云端协同。

其中部分内容属于架构研究与原型探索，文章中会区分已实现能力与设计方案。
